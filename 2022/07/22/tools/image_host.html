几个免费又好用的国内图床分享

  • 2022-07-22
  • 作者 xxy
  • 925 字

本文最后编辑于 前，其中的内容可能需要更新。

图床一般是指储存图片的服务器，有国内和国外之分。国外的图床有空间距离等因素会导致访问速度很慢，影响图片的显示速度。国内分为单线空间、多线空间和 CDN 加速三种。

我们在选择图床的时候，应该慎重。由于服务器、带宽、人员、技术投资、市场宣传等的投入经常导致图床网站好景不长，不得不关闭图片外链或者商用甚至闭站，我们在做好选择后，最好也做一下图片的备份。（推荐 GitHub 备份）

在之前《几个免费的静态网站托管平台对比》文章中，我介绍了可以使用 Vercel 或 Netlify 来零费用托管我们的静态网站，但是这两个相对比较好用的平台都有每月流量限制。为了节省流量，我们可以使用图床来托管我们网站中的图片，并使用 GitHub 仓库进行备份。

路过图床

免费公共图床，成立至今已有 11 年的历史了，它拥有无限空间，无限流量，原图保存, 全球 CDN 加速，已托管 1800 万+的图片。

优点：使用简单、免费、无限空间、无限流量，成立时间长，跑路概率相对较低。

缺点：图片加载速度一般。

官网：https://imgtu.com

注：路过图床是我正在使用以及使用最多的图床。

七牛云对象存储

国内领先的企业级云服务商提供的云存储服务。

优点：企业技术支持，有免费空间和每月免费流量，CDN 加速。

缺点：免费空间只有 10G，需要自己绑定已备案的域名，略麻烦。

官网：https://qiniu.com

注：又拍云和七牛云体验差不多，但是需要在网站底部添加他们网站的 logo。

聚合图床

一个聚合了多个免费图床的图床。

优点：一键分发，多处备份。

缺点：免费版有 1 万张图片数量限制。

官网：https://superbed.cn

ImgURL

一个开源的简单、纯粹图床程序，让个人图床多一个选择。

优点：开源，支持自建图床，支持拖拽、粘贴等多种上传方式。

缺点：个人项目，上线时间短。

官网：https://imgurl.org

开源地址：https://github.com/helloxz/imgurl

其它图床

如果有条件的话可以选择阿里云、腾讯云等知名云服务商的对象存储服务来做图床，大厂服务有保证，几乎不会出现图片外链失效的问题。
